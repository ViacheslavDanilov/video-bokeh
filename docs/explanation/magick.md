# MAGICK dataset

RGBA dataset of isolated objects, generated by a chroma-keying pipeline. **Does NOT use LayerDiffuse** — it composes DeepFloyd + SDXL with classical/learned matting on top.

> Compare with [[layer-diffuse]] (joint RGBA generation). Discussed in [[2026-04-22-pablo-magick-review]].

## Models used

- **DeepFloyd** — initial text-to-image generation on solid-color backgrounds
- **SDXL with SDEdit** — image-to-image refinement (strength=0.95) to enhance hair/fur/transparency details
- **Photoshop Subject Selection** — deep learning segmentation for intermediate object extraction

## Pipeline

![[magick-pipeline.png]]

1. **Prompt engineering** — subject prompts augmented with background color (e.g. "cat isolated on solid green background").
2. **Initial generation** — DeepFloyd generates image on a clean solid background.
3. **Least-represented color detection** — identifies the background hue least present in the foreground.
4. **Re-composite** — Photoshop extracts object and places it on a brighter/more saturated version of that hue.
5. **SDXL/SDEdit refinement** — regenerates with strength=0.95 to enhance foreground details and suppress background color bleed.
6. **Alpha extraction** — 3 methods in parallel:
    - Pixel-based chroma keying (with inpainting for gradient areas)
    - Deep learning chroma key model (trained on internal greenscreen data)
    - Photoshop segmentation/matting
    - Best matte selected via MS-SSIM; borderline cases go to human review.

## Key takeaway

MAGICK computes alpha **after the fact** using 3 separate matting algorithms — RGB/alpha alignment is **not guaranteed**. This is why [[layer-diffuse]] is preferred for training-data quality: it generates RGBA jointly, giving tighter pixel-level alignment between color and alpha.
